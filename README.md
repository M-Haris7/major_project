# Small Models Struggle to Learn from Strong Reasoners: A Code Generation Perspective

Investigating the **Small Model Learnability Gap** in code generation tasks, extending the findings of [Li et al. (2025)](https://arxiv.org/abs/2502.12143) from mathematical reasoning to the code domain. We also propose **Curriculum Distillation** as a novel improvement over static mixing strategies.

## Overview

Large language models excel at complex reasoning, and distilling their capabilities into smaller models is a common strategy. However, small models (≤3B parameters) do not consistently benefit from long chain-of-thought (CoT) reasoning or distillation from larger teachers. This project investigates whether this phenomenon — termed the **Small Model Learnability Gap** — extends to code generation, and whether dataset scaling and curriculum-based training can mitigate it.

## Research Questions

1. **Does the learnability gap exist in code generation?** Do small code models struggle with long CoT and large teacher distillation, similar to math models?
2. **Does dataset size reduce the gap?** Can scaling training data from 500 to 1000 samples mitigate the gap for small models?
3. **Does curriculum learning outperform static mixing?** Is gradually introducing complex reasoning data more effective than random blending?

## Methodology

### Dataset Preparation

| Dataset | Source | Avg Tokens | Purpose |
|---------|--------|-----------|---------|
| Short CoT | DeepSeek-R1 (code only) | 126 | Concise code solutions |
| Long CoT | DeepSeek-R1 (full reasoning) | 4,942 | Extended reasoning chains |
| Large Teacher | DeepSeek-V3 (671B MoE) | 310 | Strong model distillation |
| Small Teacher | Qwen2.5-7B-Instruct | 218 | Weak model distillation |
| Mix-Long | 80% short + 20% long CoT | 1,017 | Static mixing strategy |
| Mix-Large | 80% small + 20% large teacher | 234 | Static mixing strategy |

Long CoT and Short CoT data are sourced from [nvidia/OpenCodeReasoning](https://huggingface.co/datasets/nvidia/OpenCodeReasoning), which contains 735K pre-verified Python solutions generated by DeepSeek-R1. Teacher comparison data is generated via DeepSeek and Together AI APIs.

### Student Models

| Model | Parameters | Training Method |
|-------|-----------|----------------|
| Qwen2.5-Coder-0.5B-Instruct | 0.5B | Full SFT |
| Qwen2.5-Coder-1.5B-Instruct | 1.5B | QLoRA (4-bit) |
| Qwen2.5-Coder-3B-Instruct | 3.0B | QLoRA (4-bit) |

### Training Configurations

**Standard Training:** 2 epochs, cosine LR schedule, bf16 precision.

| Config | Full SFT (0.5B) | LoRA (1.5B, 3B) |
|--------|-----------------|-----------------|
| Learning Rate | 1e-5 | 1e-4 |
| Batch Size | 1 | 1 |
| Grad Accumulation | 8 | 8 |
| Max Seq Length | 4096 | 4096 |
| LoRA Rank | — | 16 |

**Curriculum Training (Novel Contribution):** Gradual introduction of complex data across 3 stages.

| Stage | Hard Data Ratio | Epochs | Description |
|-------|----------------|--------|-------------|
| 1 | 0% | 0.7 | 100% easy data (build foundation) |
| 2 | 20% | 0.7 | 80% easy + 20% hard (gentle introduction) |
| 3 | 50% | 0.6 | 50% easy + 50% hard (full exposure) |

Total training budget equals 2 epochs, matching standard training for fair comparison.

### Evaluation

All models are evaluated on **HumanEval** (164 problems, pass@1) using greedy decoding.

### Expected Observations

- **Learnability Gap in Code:** Small models (0.5B, 1.5B) should perform worse when trained on long CoT vs short CoT (negative Δ_Long).
- **Teacher Size Effect:** Small students should learn better from the small teacher (Qwen-7B) than the large teacher (DeepSeek-V3).
- **Mix Distillation:** Blending easy and hard data should outperform training on either alone.
- **Curriculum Advantage:** Gradually increasing difficulty should outperform static random mixing.
